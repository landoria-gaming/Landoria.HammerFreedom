# Changelog

## 1.0.11

- Prevented cold and freezing messages in Hammer worlds.
- Applied the Shift speed boost when flying straight up or down.

## 1.0.10

- Removed the server dependency; the mod is now client-only.
- Made the flight shortcut configurable, with `Z` as the default.
- Limited configured flight speed to `10` and increased the Shift boost to `x4`.
- Added an enabled-by-default setting to hide the character and held item while flying.
- Prevented frost damage in Hammer worlds.

## 1.0.9

- Migration to Valheim 1.0.x.

## 1.0.7

- Updated documentation

## 1.0.6

- Updated README.

## 1.0.4

- Add Xbox support alongside Steam.

## 1.0.3

- Add the HammerFreedom Fly video demo to the package documentation.

## 1.0.2

- Make Hammer capabilities server-authorized, including No Build Cost material recovery.

## 1.0.1

- Add server-authorized durability protection for every durable item in Hammer worlds.
- Add server-authorized material recovery for pieces dismantled under free-build modifiers.

## 1.0.0

- Initial version.
